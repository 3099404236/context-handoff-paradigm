# 实验结果与评测记录 (Results & Benchmarks)

本目录记录上下文转移范式在不同场景下的自动化测试、端到端接力验证及性能指标。

## 核心指标总结

| 测试项 / 指标 | 测量值 | 评测结论 |
| :--- | :--- | :--- |
| **状态序列化/反序列化无损率** | 100% | 认知状态（目标/记忆/变量）完备恢复 |
| **单任务快照存储体积 (Bundle Size)** | ~3.5 KB | 极轻量，远低于 GB 级操作系统虚拟机迁移 |
| **快照序列化与落盘耗时** | < 5 ms | 对长程任务执行几乎零阻碍 |
| **台式机接管加载时延 (Resume Latency)** | < 12 ms | 毫秒级恢复，即时进入下一执行阶段 |
| **多设备并发竞态防冲突 (Lease Lock)** | 100% 排他 | 严格杜绝双端写脑裂与竞态操作 |
